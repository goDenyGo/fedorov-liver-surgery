# fedorov.liver.surgery

Двомовна статична візитка: [українська версія](https://fedorov.liver.surgery/uk/) та [англійська версія](https://fedorov.liver.surgery/en/). Коренева адреса показує українську сторінку.

## 1. Редагування

- [data/site-content.json](data/site-content.json) — тексти обома мовами, контакти, посилання, метадані та дані для vCard. Оновлюйте обидві мовні версії. Опис полів є в [інструкції з контенту](data/CONTENT-BRIEF.md).
- [templates/page.html](templates/page.html) — структура сторінки; [css/style.css](css/style.css) — оформлення.
- [img/](img/) — зображення. Якщо додаєте новий портрет, оновіть шлях до нього в JSON.

Папка `dist/` генерується під час збірки. Не редагуйте й не комітьте її. Контактні картки vCard публічні; не додавайте до JSON секрети чи дані пацієнтів.

## 2. Локальний запуск

Потрібні Python 3.12+ і Node.js 24+. Додаткові пакети встановлювати не потрібно. З кореня проєкту виконайте:

```sh
python3 scripts/build.py
python3 -m http.server 8000 --directory dist
```

Перевірте [українську](http://localhost:8000/uk/) та [англійську](http://localhost:8000/en/) сторінки. Після змін повторіть команду збірки в іншому терміналі й оновіть сторінку в браузері. Сервер перезапускати не потрібно.

## 3. Публікація

Закомітьте потрібні зміни й надішліть їх у `main` напряму або через злиття pull request. GitHub Actions автоматично запустить тести, збере сайт і опублікує його в GitHub Pages. Для відкритого pull request виконуються лише перевірки та збірка.

Перевірте результат у вкладці **Actions** → **Build and publish static site**. Якщо перевірки або збірка не пройдуть, попередня версія залишиться доступною.
