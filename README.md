# fedorov.liver.surgery

Двомовна статична візитка. Редаговане джерело контенту —
[data/site-content.json](data/site-content.json). GitHub Actions автоматично
створює готові HTML-сторінки та публікує їх через GitHub Pages після push у main.

- `/uk/` — українська сторінка; `/en/` — англійська.
- `/` містить українську сторінку для сумісності старих посилань; canonical — `/uk/`.
- Тексти, посилання, портрет, метадані та vCard доступні без JavaScript.
- JavaScript потрібний лише для згортання мобільного меню.
- Анкета, редакційні примітки, шаблони та документація не входять до артефакту сайту.

## Зміна контенту

1. Відредагуйте тексти обох мов, контакти чи URL у JSON. Формат полів:
   [data/CONTENT-BRIEF.md](data/CONTENT-BRIEF.md).
2. За потреби додайте зображення у img/ та змініть відповідний шлях у JSON.
3. Надішліть зміни до main. Workflow **Build and publish static site** виконає
   перевірки, генерацію та публікацію. Якщо перевірка не пройде, новий сайт
   не публікується; попередня версія залишається доступною.

Не редагуйте згенеровані HTML: вони створюються у dist/ та не комітяться.
Для зміни структури використовуйте templates/page.html; для стилів — css/style.css.

## Локальний перегляд

Потрібні Python >=3.12 і Node.js >=24. Встановлення npm/pip залежностей не потрібне.

```sh
python3 scripts/build.py
python3 -m http.server 8000 --directory dist
```

Відкрийте http://localhost:8000/uk/ або http://localhost:8000/en/.
Після кожної зміни JSON/шаблону/стилів повторіть build і оновіть сторінку.
Відкривати вихідний шаблон або запускати сервер у корені репозиторію не потрібно.

## Перевірки

```sh
python3 -m unittest discover -s test -p 'test_*.py'
node --test test/content.test.mjs
python3 scripts/build.py
node --check js/main.js
git diff --check
```

## Контакти та приватність

Обидві vCard автоматично генеруються з анкети під час build; кнопки ведуть
на готові файли. Старий URL vcard/denys-fedorov.vcf збережено як англійську копію.
Телефон і робоча адреса залишаються лише у vCard, окремого блока на сторінці немає.
Контактна секція має data-nosnippet; robots.txt просить не обходити vcard/.
Це добровільні правила роботів, а не захист доступу. Картки публічні.
Анкета не публікується в Pages, але якщо GitHub-репозиторій публічний,
її вміст та історія залишаються доступними через GitHub. Секретів у JSON бути не повинно.
