# Іконки

Логотипи Telegram, YouTube, ORCID, Google Scholar, ResearchGate, Scopus:
Simple Icons, https://simpleicons.org (завантажено з https://cdn.simpleicons.org/,
29.10.2026). SVG збережені локально, без запитів до CDN від відвідувачів.
Simple Icons: CC0; назви та знаки сервісів належать відповідним власникам.
Book та email — власні прості SVG-піктограми, не логотипи сторонніх сервісів.
Іконки декоративні (alt порожній), видимі текстові підписи збережено.
Contacts — власна SVG-іконка записної книги з силуетом і вкладками,
візуально натхненна адресною книгою iOS; не копія офіційного Apple asset.
Усі іконки адаптовані до палітри сайту: основний #1F6F78, деталі записної
книги #164f57 та #f5f8f7. Форми оригінальних знаків збережено.
