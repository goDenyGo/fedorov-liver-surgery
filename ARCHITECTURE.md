# Архітектура візитки

Сайт — статичні HTML/CSS/ES modules на GitHub Pages. Єдине редаговане джерело
контенту — data/site-content.json; зображення — окремі файли за шляхами з JSON.
index.html містить структуру й data-bind атрибути, а не дублікати контенту.
js/main.js завантажує JSON без кешу, заповнює тексти/посилання/метадані й
обирає мову. Зміна мови під час fetch не дозволяє старій відповіді перезаписати
новіший вибір. Помилка читання показується користувачу; JSON повторно можна
запросити перемиканням мови або перезавантаженням. Порожні посилання сховані;
URL обмежено протоколами http/https/mailto, тексти вставляються textContent.

js/vcard.js — спільна чиста функція генерації UA/EN vCard 3.0 (UTF-8, CRLF,
folding 75 bytes). Браузер створює blob URL для актуальних карток; Node CLI
scripts/generate-vcards.mjs використовує ту саму функцію для legacy-файлів.
Старі vcard/*.vcf — сумісні копії, не джерело даних для кнопок сайту.

JavaScript необхідний для вмісту сторінки. scripts/generate-metadata.mjs
генерує статичний head із тієї самої анкети: українські title/description,
Open Graph, Twitter Card та canonical. Роботи без JS отримують повне прев’ю;
main.js синхронізує UA/EN title/description та OG locale під час перемикання.
Після зміни meta або socialPreview потрібно запускати генератор перед push;
режим --check виявляє застарілий HTML. Окремого серверного runtime немає.
JSON публічний, robots.txt та
 data-nosnippet не контролюють доступ. Телефон та адреса не виводяться як блоки
сторінки, але є у картках і анкеті.

Перевірка: node --test test/content.test.mjs; локальний браузер через HTTP.
